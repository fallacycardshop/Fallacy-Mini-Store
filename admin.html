Hide a Card for Auction

Paste one Card ID or a whole batch — separated by commas, spaces or new lines, so a column copied straight out of a spreadsheet works. You'll see every condition listed under each ID and how many are genuinely still available, then you can pull the whole batch for a set number of hours so they don't compete with your auctions. They come back automatically when the time is up — nothing to remember.

Reset Sold Counts

This clears the running "sold" tally for every card, so newly restocked quantities in your CSV will display exactly as entered. It does not touch anyone's in-progress checkout — active payment sessions expire on their own as normal.
