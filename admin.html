Recent Orders

Every confirmed order is saved here the moment stock is decremented — independently of the notification email. If an email never arrives, the full order is still recoverable from this list.

Slow Release Scheduling

Upload all your new stock to the CSV at once, then release it gradually. Scheduled cards stay completely hidden from the store until their release time, then appear in the Newly in stock! row at the very top. After their first day they drop into the normal rows and rotate with everything else.

Settings

Release New Stock

First-time setup required. Mark everything currently in your CSV as already released, so only rows you add later get drip-scheduled.

Featured Section Heading

Headings for the two special rows on the store, plus the promo banner. Change them whenever you like — “New in!”, “Weekend picks”, and so on. Emoji work fine. Shoppers see changes within a minute; no redeploy needed.

Hide a Card for Auction

Paste one Card ID or a whole batch — separated by commas, spaces or new lines, so a column copied straight out of a spreadsheet works. You'll see every condition listed under each ID and how many are genuinely still available, then you can pull the whole batch for a set number of hours so they don't compete with your auctions. They come back automatically when the time is up — nothing to remember.

Reset Sold Counts

This clears the running "sold" tally for every card, so newly restocked quantities in your CSV will display exactly as entered. It does not touch anyone's in-progress checkout — active payment sessions expire on their own as normal.
