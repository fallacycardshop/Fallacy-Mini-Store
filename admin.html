Recent Orders

Every confirmed order is saved here the moment stock is decremented — independently of the notification email. If an email never arrives, the full order is still recoverable from this list.

Auction Promo Image

For cards that aren’t in the store inventory. Upload the card photos to /images in the repo, then list the filenames below — one per line. Highlighted cards are fanned across the centre, overlapping the rest, which also hides the scan borders.

Promo Image Generator

Builds a collage of everything currently in the “Newly in stock!” row, ready to attach to a Telegram post. No passphrase needed — it reads the same public catalogue shoppers see.

Shopfront Proof Figures

The headline numbers shoppers see when they tap the recent-sales ticker. Entered by hand because they cover the whole business — the auction channel as well as this store — which nothing here can measure. Confirmed store orders are added on top automatically, so the cards figure keeps climbing between updates. Whenever you re-enter the cards total it becomes the exact number shown — the running count resets, so nothing is double-counted.

Sales History

Every card sold, with the date, condition and the price it actually went for (after any discount). Built from stored orders, so it covers sales from when order backup went live — the raw sold counters carry no dates.

Adjust what's already scheduled

Align expiry times

Puts every card in the “Newly in stock!” row on the same release time so they all expire together. Uses the earliest time, so nothing gets its stay extended.

Remove From “Newly In Stock”

Drops a card out of the Newly in stock row early. It stays on sale — it just falls into Featured or All Cards straight away. Leave the Card ID blank to clear the whole row.

Publish Stock Now

Push a card’s current CSV stock live immediately, skipping the queue. Use after editing the Stock column when you don’t want to wait for a scheduled release. Covers every condition of that Card ID.

First-time setup required. Mark everything currently in your CSV as already released, so only rows you add later get drip-scheduled.

Featured Section Heading

Headings for the two special rows on the store, plus the promo banner. Change them whenever you like — “New in!”, “Weekend picks”, and so on. Emoji work fine. Shoppers see changes within a minute; no redeploy needed.

Card Lookup & Auction Hiding

Look up any Card ID to check its price, stock and status, or pull it from the store during an auction. Paste one Card ID or a whole batch — separated by commas, spaces or new lines, so a column copied straight out of a spreadsheet works. You'll see every condition listed under each ID and how many are genuinely still available, then you can pull the whole batch for a set number of hours so they don't compete with your auctions. They come back automatically when the time is up — nothing to remember.

Reset Sold Counts

This clears the running "sold" tally for every card, so newly restocked quantities in your CSV will display exactly as entered. It does not touch anyone's in-progress checkout — active payment sessions expire on their own as normal.
